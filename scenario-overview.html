Neubility · 다목적지 검체 배송

스테이션 → 여러 부서, 한 번에 보내는 배송 시나리오

현장에서 검체를 한 번의 요청으로 여러 목적지에 순차 배송하는 전체 흐름입니다. 발송인이 뉴비오더 앱에서 다목적지를 지정하면, 시스템이 경로를 만들고 로봇이 순차 배송하며, 관제사는 NCC에서 다구간 임무를 모니터링·원격제어합니다. 각 단계의 실제 화면을 아래에 임베드했습니다.

발송인 · 수령자
고객사 현장 인원(간호사 등). 검체를 보내고, 각 부서에서 받습니다.
뉴비오더 — 모바일 웹
고객사 관리인
고객사 운영 담당. 배송 현황을 한눈에 조회합니다.
NCC — 메인 페이지
관제사 내부
뉴빌리티 관제 인원. 로봇 배차·경로·이상을 관제하고 필요 시 원격제어합니다.
NCC — 모니터링 · 원격제어

1

배달 요청 — 다목적지 지정

발송인이 뉴비오더 앱에서 출발 스테이션과 여러 도착지 + 목적지별 받는 분을 한 화면에서 입력하고 발송합니다.
발송인 · 뉴비오더
신규 기능 — 다목적지 · 도착지를 여러 개 추가·삭제·순서변경(↕)하고, 지점마다 받는 분 정보를 함께 입력합니다.
  • 1타 부서로 보낼 검체 발생 인지
  • 2뉴비오더 앱 접속 · 문서 배달 선택
  • 3출발지(스테이션) 지정 · 보내는 분 입력
  • 4도착지 여러 곳 선택 · 순서 지정경유 추가 / 삭제 / ↕ 순서변경
  • 5목적지별 받는 분(이름·연락처·메시지) 입력
  • 6문서 배달 보내기 → 요청 완료 확인
뉴비오더 · 배달 요청 열기
출발+도착 통합 · 지점별 받는 분 입력
2

접수 · 배차 · 경로 생성

시스템이 다건 배달 경로를 만들어 로봇을 배차하고 출발지로 이동시킵니다. 관제사는 NCC 모니터링에서 임무를 확인하고, 관리인은 메인 페이지에서 현황을 봅니다.
시스템 · 플랫폼 관제사 · NCC 모니터링 관리인 · NCC 메인
다건 배달 자동 경로화 · 여러 목적지를 최적 순서의 단일 임무로 묶어 배차합니다.
  • 1시스템 — 다건 배달 시나리오로 로봇 경로 생성
  • 2스테이션 인근 대기 로봇 배차 · 출발지로 이동
  • 3관제사 — NCC 모니터링에서 임무·로봇 상태 확인
  • 4관리인 — NCC 메인에서 배송 현황 조회

3

검체 적재

로봇이 출발지 스테이션에 도착하면 발송인에게 알림이 가고, 적재함이 자동으로 열려 검체를 싣습니다.
발송인 · 뉴비오더 로봇 · 빌리
도착 알림 · 적재함 원격 열림 · 이용내역 카드에서 상태를 확인하고 적재함 열기로 검체를 싣습니다.
  • 1시스템 — 로봇 출발지 도착 알림 발송
  • 2발송인 스테이션으로 이동
  • 3스테이션 문 · 적재함 자동 열림 확인안 열릴 경우 운영 대응
  • 4검체 적재 후 적재함 닫기
뉴비오더 · 이용내역 열기
진행 상태 · 적재함 열기
4

순차 배송 — 다구간 원격제어

로봇이 출발해 목적지를 순서대로 방문합니다. 관제사는 NCC 원격제어에서 다구간 진행을 실시간으로 모니터링하고, 필요 시 개입합니다.
로봇 · 빌리 관제사 · NCC 원격제어
다구간 원격제어 · 구간별 스테퍼·진행 게이지·미니맵으로 순차 방문을 관제합니다.
  • 1로봇 출발 (스테이션 문 열림 → 주행)
  • 2목적지 1 → 2 → 3 순차 방문 · 구간별 도착
  • 3관제사 — 구간 진행·이상 모니터링, 필요 시 원격 개입
  • 4마지막 목적지 후 스테이션 복귀
NCC · 원격제어 (다구간) 열기
다구간 스테퍼 · 실시간 위치 · 구간 진행
5

수령

각 목적지에 도착하면 해당 수령자에게 알림이 가고, 적재함을 열어 검체를 수령합니다. 모든 목적지 완료 후 로봇은 복귀합니다.
수령자 · 뉴비오더
목적지별 수령 알림 · 각 지점 도착 시 그 목적지의 받는 분에게만 알림이 전달됩니다.
  • 1목적지 도착 → 수령자에게 도착 알림
  • 2수령자 적재함 열어 검체 수령
  • 3다음 목적지로 이동 · 반복
  • 4전체 완료 → 로봇 스테이션 복귀
